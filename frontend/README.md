# Front end (React)

React + TypeScript front end of the Recruiting and Application Management System, built with Vite.

```bash
npm install      # once
npm run dev      # http://localhost:5173
npm test         # Vitest
```

The development server forwards every `/api` request to the Spring Boot back end on port 8080,
so start the back end first (see the README at the repository root). Sign in with one of the
sample accounts listed there (password `Demo-pass-2026`).
